# H-Visuals Studio Rebrand Plan

## Goal
Reposition H-Visuals as a premium studio for **Visual Strategy & Creative Direction**, with **Ideas, made visible.** as the central brand idea. The existing training business remains fully functional, but moves behind a clear secondary entry point rather than leading the homepage.

## Visual direction
Build the selected **Editorial Studio Layout** using the locked H-Visuals identity:

- Forest Green `#18542A` as the dominant surface and navigation colour
- Cream `#F3E8CC` for page backgrounds and breathing room
- Sunshine `#FFC926` for calls to action, links, and selected highlights
- Tomato, Carrot, and Kiwi only as occasional editorial accents
- Obviously when available, with Archivo Black as the dependable display face; DM Sans for body copy; Instrument Serif for rare editorial emphasis
- Spacious asymmetry, oversized typography, thin rules, numbering, organic leaf forms, restrained hand-drawn marks, and intentional colour blocks
- No gradients, generic agency styling, excessive effects, or decorative clutter

## Site structure
- Make `/` the studio homepage in this order: navigation, editorial hero, selected work, services, about, creative approach, media grid, studio call to action, footer.
- Add dedicated `/work`, `/services`, `/journal`, and `/contact` pages with distinct metadata and matching navigation.
- Keep `/about` but reposition it around the studio and Emmanuel Haruna using only confirmed facts.
- Add a clear secondary training landing page that introduces H-Visuals Creative Training and links into the existing `/courses`, `/pricing`, `/faq`, `/auth`, and `/portal` journeys.
- Preserve all existing training, enrolment, Paystack, authentication, student portal, admin, and agent-integration behaviour.
- Keep existing public URLs working and update internal navigation coherently.

## Homepage and studio pages
- Use the brief’s hero copy: **Visual Strategy & Creative Direction**, **We Make Ideas Visible**, and the supplied supporting sentence.
- Build numbered project cards from the existing work imagery, with image, name, and real category only. Use restrained scale and overlay interactions.
- Present the six requested services in a cream-and-green editorial composition with Sunshine icon accents.
- Build the About and Creative Approach sections around purpose, strategy, growth, and execution without inventing clients, awards, dates, team size, or results.
- Turn the preserved videos and design work into a refined media grid with filters based only on categories supported by the current assets.
- Add a direct contact page and studio inquiry path using the existing verified email, phone, WhatsApp, and social links.
- Treat Journal as an honest editorial index or coming-soon page if no real articles exist; do not fabricate posts.

## Asset protection
- Preserve unchanged: both portraits, the instructor portrait, Spacedit, Children’s Day, Eid, EPB, Merci Luxe, all five uploaded videos, H-Visuals logo, The Media Guy logo, The Outlook Podcast logo, CapCut logo, and Alight Motion logo.
- Reframe these assets through layout, cropping, spacing, labels, and hover behaviour only; do not recolour or cover the project work with heavy branding.
- Retire the three generic training hero images and the two generic course thumbnails from prominent studio presentation. Replace only where necessary, using authentic Nigerian editorial imagery or typography-led graphic compositions.
- Keep uncertain assets rather than deleting them.

## Training area
- Restyle training pages to the shared H-Visuals system without changing curricula, prices, upgrade rules, testimonials, materials, forms, or payment logic.
- Move the current training-heavy homepage content into the training area rather than deleting it.
- Keep student and admin pages clear and task-focused while applying the new colours and typography consistently.

## Accessibility, responsiveness, and performance
- Verify desktop, laptop, tablet, and mobile layouts with no horizontal overflow or overlapping text.
- Maintain semantic headings, visible keyboard focus, accessible controls, useful alt text, readable contrast, and reduced-motion support.
- Avoid Sunshine body text on Cream and keep decorative motion subtle.
- Lazy-load portfolio media, retain metadata loading for videos, and avoid heavy animation libraries.

## SEO and technical details
- Preserve the current routes and sitemap behaviour while adding the new studio routes.
- Give every content page a unique title, description, Open Graph title/description, canonical URL, and suitable structured data where factual.
- Update the root brand metadata from training-led to studio-led while keeping training page metadata specific to training.
- Keep the existing TanStack routing, Lovable Cloud backend, authentication boundaries, payment endpoints, and MCP integration intact.
- Implement the selected composition with semantic design tokens in the shared stylesheet and reusable studio components.

## Validation
- Check all navigation, contact, training, enrolment, login, portal, admin, and payment entry points.
- Confirm every protected image and video remains present and unmodified.
- Test the final presentation at desktop and mobile sizes, verify reduced motion and keyboard navigation, and resolve any build or runtime errors before completion.
